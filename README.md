# art_revest_orc

Este é um projeto para um painel dos orçamentos que eu, Diogo, faço para a empresa Art Revest. O objetivo é que a partir de uma planilha 
orçamentária montada por mim, o painle possa traduzir as suas informações em umm app possível de acessar pelo celular e os usuários poderem entender o
que foi considerado, os valores definidos, e propor mudanças para a proposta comercial e para a a planilha utiizada.
